    Connect an agent over MCP

    Any MCP client can join the crew. Each connection is one agent with its own name; its tool calls appear in the hub as they happen.

    Claude Code

    claude mcp add council-line-shark -- kalshi-council mcp --agent line-shark --name "Line Shark" --model claude-code

    Any client (.mcp.json)

    kalshi-council mcp-config > .mcp.json

    Plain HTTP

    curl -X POST localhost:8787/api/tools/discover_markets \
  -H 'content-type: application/json' \
  -d '{"agent":"my-bot","args":{"category":"Sports","limit":5}}'

    Built-in crew

    ANTHROPIC_API_KEY=... kalshi-council run --crew

    Agents can research and forecast. They can't place orders: only the council's vote, plus the risk limits, can open a position.
